# 데이터셋 설명 (DATA_GUIDE)

최종 파일 3개(`final_result/`)를 데이터별로 **출처 → 원본 생김새 → 원본 열 → CSV 열 → 코드 뜻 → 연도별 통일 → 최종 열** 순으로 설명한다. 작업 과정과 검사 결과는 [PROCESS.md](PROCESS.md).

공통 사항
- 단위: 시정촌(市町村). 정령시는 구(区) 단위이지만 과소지역에는 정령시가 없어 최종 파일은 시·정·촌뿐이다.
- 지역 코드 `muni_code`: 全国地方公共団体コード 5자리. 앞 2자리 도도부현(01 北海道 … 47 沖縄県), 뒤 3자리 시정촌. 2026년 기준으로 통일.
- 세 파일 모두 727곳 × 17년 = 12,359행, 행 순서 동일. `year`와 `muni_code`로 붙는다.
- 인코딩 UTF-8(BOM), 빈칸 = 값 없음.

### 1.4 코드
- `muni_code`: 全国地方公共団体コード. 총무성 코드표 https://www.soumu.go.jp/denshijiti/code.html (작업엔 쓰지 않았고 파일 안의 코드를 그대로 씀)
- `row_type`: `city` 시 / `town` 정 / `village` 촌. (전국 파일에는 `pref` 도도부현 합계, `city_agg` 정령시 합계, `ward` 정령시의 구, `special_ward` 도쿄 23구, `gun_agg` 군 소계, `island_agg` 도쿄 섬 합계, `zero_pop` 인구 0도 있음)

## 2. 공시지가 `chika_kaso.csv`

### 2.1 출처
국토교통성 **国土数値情報 L01 地価公示** (매년 1월 1일 기준 전국 약 2만 6천 표준지의 ㎡당 평가액. 한국의 표준지 공시지가).

- 받기: 「ダウンロードするデータの選択」에서 **全国** 체크 → 표에서 2010~2026 행의 「一括DL」 체크 → 「一括ダウンロード」. 파일 `L01-10_GML.zip` … `L01-26_GML.zip`
- 직접 주소: `https://nlftp.mlit.go.jp/ksj/gml/data/L01/L01-YY/L01-YY_GML.zip` (YY = 연도 2자리)

## 3. 실거래가 `torihiki_kaso.csv`

### 3.1 출처
국토교통성 **不動産情報ライブラリ(reinfolib) API `XIT001` 不動産取引価格情報** (매매 당사자 설문 기반 실거래가. 한국의 국토부 실거래가).
- API 설명서: https://www.reinfolib.mlit.go.jp/help/apiManual/xit001/ — 키 신청 https://www.reinfolib.mlit.go.jp/api/request/ (개인, 조사·연구, 약 5영업일)
- 웹 화면 일괄 다운로드는 2024년 개편으로 없어져 API 사용. 키는 환경변수 `REINFOLIB_API_KEY`에만 두고 저장소·문서에 적지 않는다.
- 호출: 연도 × 분기 × 도도부현(47) × `priceClassification=01`(取引価格만; 02 成約価格은 2021~ 별도 출처라 제외). 응답 JSON을 그대로 `Reinfolib/raw/`에 저장.
- 기간: 2010년 1분기 ~ 2026년 1분기 (2026년 2분기~는 미공개). 원본은 2005년 3분기부터 있음.
- reinfolib는 과거 거래를 **이미 현재(2026년) 시정촌 코드로** 제공한다 (2024년 신설 浜松市中央区에 2010년 거래가 붙어 있음). 그래서 코드 통일이 필요 없었다.
