# panel.csv 열 사전

- 행 = 시정촌 × 연도. 1,741 시정촌(시정촌 + 도쿄 23구, 정령시는 시 전체) × 2010~2025 = 27,856행.
- 만든 스크립트: `00_build_panel.py`. 입력은 전부 `final_result2/`.
- 2026년은 실거래가 1분기만 있어 제외.

## 식별

| 열 | 뜻 | 원본 | 계산 |
|---|---|---|---|
| muni_code | 시정촌 코드 (2026년 기준 5자리) | jp_pop_detail.muni_code | 그대로 |
| year | 연도 | jp_pop_detail.year | 그대로 |
| pref_code | 도도부현 코드 2자리 | muni_code | 앞 2자리 |

## 가격·거래 건수

| 열 | 뜻 | 원본 | 계산 |
|---|---|---|---|
| n_land | 토지만(宅地(土地)) 거래 건수 | torihiki.csv type | 연도·시정촌별 건수 |
| log_p_land | 토지만 ㎡당 가격 중앙값의 log | torihiki trade_price, area_sqm | 거래별 trade_price ÷ area_sqm → 중앙값 → log. n_land < 5 이면 빈칸 |
| n_landbldg | 토지+건물(宅地(土地と建物)) 거래 건수 | 위와 같음 | 위와 같음 |
| log_p_landbldg | 토지+건물 ㎡당(토지면적 기준) 가격 중앙값의 log | 위와 같음 | 위와 같음. n_landbldg < 5 이면 빈칸 |
| n_condo | 아파트(中古マンション等) 거래 건수 | 위와 같음 | 위와 같음 |
| log_p_condo | 아파트 ㎡당(전유면적 기준) 가격 중앙값의 log | 위와 같음 | 위와 같음. n_condo < 5 이면 빈칸. 면적은 등기부 전유면적(국토교통성 자료 기준) |
| n_chika | 공시지가 주택지 지점 수 | chika.csv n_residential | 그대로 |
| log_p_chika | 공시지가 주택지 ㎡당 가격 중앙값의 log | chika.csv med_residential | log. 지점 0이면 빈칸 |

## 인구

| 열 | 뜻 | 원본 | 계산 |
|---|---|---|---|
| pop_total | 총인구 (일본인 주민) | jp_pop_detail.pop_total | 그대로 |
| log_pop | log 총인구 | pop_total | log |
| child_rate | 유소년 비중 % (0–14세) | age_0_4 + age_5_9 + age_10_14 | ÷ pop_total × 100 |
| youth_rate | 청년 비중 % (15–34세) | age_15_19 … age_30_34 | ÷ pop_total × 100 |
| middle_rate | 중장년 비중 % (35–64세) | age_35_39 … age_60_64 | ÷ pop_total × 100 |
| elderly_rate | 고령 비중 % (65세 이상) | age_65_69 + age_70_74 + age_75_79 + age_80p | ÷ pop_total × 100 |
| aging_rate | 고령화율 | = elderly_rate | 같은 값 |
| share_15_19 | 15–19세 비중 % (민감도: 청년을 20–34로 바꿀 때 분리) | age_15_19 | ÷ pop_total × 100 |
| share_20_34 | 20–34세 비중 % (민감도) | age_20_24 … age_30_34 | ÷ pop_total × 100 |
| share_65_74 | 65–74세 비중 % (민감도: 75세 이상 분리) | age_65_69 + age_70_74 | ÷ pop_total × 100 |
| share_75p | 75세 이상 비중 % (민감도) | age_75_79 + age_80p | ÷ pop_total × 100 |

주의: 원본에서 78행(27,856행 중)은 연령별 합계가 총인구보다 1~6명 작음(연령 불명자가 총인구에만 포함). 분모는 총인구를 그대로 써서 네 비중의 합이 100에서 최대 0.005%p 모자랄 수 있음.

## 장기차분용 끝점 3년 평균

- 열 이름: `avg3_` + 원래 열 이름. 대상: log_p_land, log_p_landbldg, log_p_condo, log_p_chika, log_pop, child_rate, youth_rate, middle_rate, elderly_rate, share_15_19, share_20_34, share_65_74, share_75p.
- 끝점 연도(2010, 2015, 2020, 2025) 행에만 값이 있고 다른 연도는 빈칸.
- 창: 2015 → 2014~2016, 2020 → 2019~2021, 2010 → 2010~2012(2009년 없음), 2025 → 2023~2025(2026년은 1분기뿐).
- 가격은 창 안에서 값 있는 해만 평균, 하나도 없으면 빈칸. 인구·비중은 전 연도 값 있음.
- 끝점 값 자체는 해당 연도 행의 원래 열을 그대로 쓰면 됨. 5년 차분은 R에서 끝점 행끼리 빼서 계산.
